# MedScribe – versioni di prova

Questo repository contiene solo i pacchetti di prova di MedScribe, protetti da password. Il codice non è pubblico.

## Come installare una versione di prova

1. Scaricate il file `.7z` dall'ultima [release](../../releases/latest).
2. Installate **7-Zip** (gratuito) da [www.7-zip.org](https://www.7-zip.org), se non lo avete già.
3. Clic destro sul file → **7-Zip → Estrai qui**, e inserite la password che vi ha mandato Daniele.
4. Aprite la cartella estratta e seguite il file **LEGGIMI.txt**.

## Avvertenze

- Versione di sviluppo, solo per **visite simulate**: nessun paziente o dato reale.
- La password e le chiavi API vengono inviate a parte e sono personali.
